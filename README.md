# Bloom Filter

A lightweight Bloom filter implementation in C with automatic parameter calculation.

## Features

- **Automatic parameter calculation** — Just provide expected element count (`n`) and target false positive rate (`p`), the optimal bit array size (`m`) and hash function count (`k`) are computed automatically using standard formulas:

$$
m = -\frac{n \ln p}{(\ln 2)^2}, \quad k = -\frac{\ln p}{\ln 2}
$$

- **Double hashing** — Uses BKDRHash and DJBHash combined via double hashing to generate `k` independent hash positions per element.
- **Memory efficient** — Bit array stored as raw bytes with 8-bit packing.
- **Thread-safe data structure** — No internal global state; each filter instance is independent.

## API Reference

### Data Type

```c
typedef struct Bloom_Filter Bloom_Filter;
```

Opaque structure; access fields only through provided functions.

### Memory Management

```c
Bloom_Filter* Bloom_Filter_Create(size_t n, double p);
```
Creates a new Bloom filter.
- `n`: Expected number of elements to insert.
- `p`: Target false positive rate (0 < p < 1).
- Returns pointer to the filter, or `NULL` on failure (invalid parameters or allocation error).

```c
void Bloom_Filter_Destroy(Bloom_Filter* bf);
```
Destroys the filter and frees all associated memory. Safe to pass `NULL`.

```c
void Bloom_Filter_Clear(Bloom_Filter* bf);
```
Resets the filter to empty state. All previously inserted elements become untracked. Safe to pass `NULL`.

### Operations

```c
void Element_Mark(Bloom_Filter* bf, const char* str);
```
Inserts a string into the filter.

```c
bool Element_Query(Bloom_Filter* bf, const char* str);
```
Checks whether a string may exist in the filter.
- Returns `true` if the element **may** exist (could be a false positive).
- Returns `false` if the element **definitely does not** exist.

### Statistics

```c
double bloom_filter_current_false_positive_rate(Bloom_Filter *bf);
```
Returns the theoretical current false positive rate based on the number of inserted elements so far.

$$
p = \left(1 - e^{-kn/m}\right)^k
$$

## Quick Start

```c
#include "bloom_filter.h"
#include <stdio.h>

int main(void) {
    // Create a filter expecting 10000 elements with 1% false positive rate
    Bloom_Filter *bf = Bloom_Filter_Create(10000, 0.01);
    if (!bf) return 1;

    // Insert some elements
    Element_Mark(bf, "apple");
    Element_Mark(bf, "banana");
    Element_Mark(bf, "cherry");

    // Query
    printf("apple?  %s\n", Element_Query(bf, "apple")  ? "may exist" : "not found");
    printf("grape?  %s\n", Element_Query(bf, "grape")  ? "may exist" : "not found");

    // Check current false positive rate
    printf("Current false positive rate: %.4f\n",
           bloom_filter_current_false_positive_rate(bf));

    Bloom_Filter_Destroy(bf);
    return 0;
}
```

## Compilation

```bash
gcc -o program main.c bloom_filter.c -lm
```

Requires linking with the math library (`-lm`) for `log`, `ceil`, `exp`, and `pow`.

## How It Works

### Parameter Calculation

Given `n` (expected elements) and `p` (target false positive rate):

```c
m = ceil(-n * ln(p) / (ln 2)²)    // bit array size
k = max(ceil(-ln(p) / ln 2), 1)   // number of hash functions
```

### Double Hashing

For each element, two base hashes are computed:

```c
h1 = BKDRHash(str)    // polynomial hash, seed = 131
h2 = DJBHash(str)     // Bernstein hash, initial = 5381
```

Then `k` bit positions are generated by:

```c
pos_i = (h1 + i * h2) % bit_size    // for i = 0, 1, ..., k-1
```

This avoids computing `k` independent hash functions while maintaining good distribution.

## Notes

- The filter does **not** store the original elements. False positives are possible but false negatives are not.
- Use `Bloom_Filter_Clear` to reuse a filter without deallocating memory.
- The `align_up` macro rounds the bit array size up to the nearest byte boundary for memory efficiency.
